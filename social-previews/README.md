# Social Preview

![Social Preview](social-previews/RU-Socrates-preview.png)

This folder contains the HTML template for the R U Socrates social preview image.

To generate the PNG:
1. Open `RU-Socrates-preview.html` in your browser
2. Take a screenshot at 1280x640 resolution
3. Save as `RU-Socrates-preview.png` in this folder
