## Enterprise Edition

**Custom Pricing**

Perfect for:
- Research institutions
- Enterprises
- Startups building on R U Socrates

### Enterprise Features

1. **Security & Compliance**
   - SSO (SAML, OAuth 2.0)
   - Role-based access control (RBAC)
   - Full audit logging
   - SOC 2 and GDPR compliant
   - On-premise deployment option

2. **Team Collaboration**
   - Multi-user workspaces
   - Shared task templates
   - Team analytics dashboard
   - Commenting and annotations

3. **Cloud & Infrastructure**
   - S3 cloud backup via Litestream
   - PostgreSQL option (instead of SQLite)
   - Horizontal scaling support
   - API access for integrations

4. **Support & Success**
   - 24/7 priority support
   - Dedicated account manager
   - Custom onboarding and training
   - SLA-backed uptime guarantees

### Pricing

Pricing is custom based on:
- Number of users
- Deployment model (cloud/on-prem)
- Support level needs
- Custom integration requirements

Contact: **sales@rusocrates.ai** for a quote.

**Can I use Community Edition for commercial purposes?**
No, the PolyForm Noncommercial license prohibits commercial use.

**Can I self-host Enterprise Edition?**
Yes, on-prem deployment is a core enterprise feature.

**What payment methods do you accept?**
Credit card, bank transfer, and invoice for enterprise customers.
